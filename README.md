#  To-Do App

Aplicación web de lista de tareas desarrollada con **HTML, CSS y JavaScript** que permite gestionar tareas diarias de forma sencilla y eficiente.

El proyecto fue creado para practicar manipulación del DOM, manejo de eventos y uso de **localStorage** para la persistencia de datos.

---

##  Funcionalidades

- ➕ Agregar nuevas tareas
- ✔️ Marcar tareas como completadas
- 🗑️ Eliminar tareas
- 💾 Guardado automático en localStorage
- ⌨️ Agregar tareas usando el teclado (Enter)
- 🔄 Persistencia de datos al recargar la página

---

##  Tecnologías Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- LocalStorage  

---

## Objetivo del proyecto

- Practicar manipulación del DOM
- Manejo de eventos de usuario
- Persistencia de datos en el navegador
- Organización de código en JavaScript
